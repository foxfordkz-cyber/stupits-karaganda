# Только синтетическое воспроизведение
Эти адаптеры проверяют реальный запуск процессов и обмен файлами. core и language
читают заранее подготовленные находки; они не обнаруживают ошибки самостоятельно.
Конфигурация помечена mode=synthetic и требует флага --synthetic.
Здесь нет экспорта исправлений и нет настоящих одобрений носителя.
