# Проверка интегратора

Локальная среда: Windows, Node.js v24.14.1, Flutter 3.47.4, Dart 3.13.3.

- Автоматические unit/integration проверки охватывают схемы, реальные subprocess, неизменность входов, ICU, placeholders, ручную оценку, дубли и целостность пакета. Последний полный прогон: 144 теста, 142 passed, 0 failed, 2 skipped из-за запрета hardlink/symlink песочницей.
- `npm run check`: успешно.
- Синтетический `run-pipeline`: реальные процессы прошли normalize/core/language/merge/render. Находки воспроизводятся из fixture; качество модели не измеряется.
- `npm run integration-smoke`: локально успешно выполнены настоящие Flutter --version, pub get и gen-l10n, затем упаковка и повторная проверка. Evidence содержит хэши конкретных ARB, журнала и сгенерированного Dart-кода. Сценарий использует чистые вымышленные строки, 0 исправлений и 0 заявленных человеческих проверок.
- Исходный коммит 07ed416 прошёл все пять jobs [GitHub Actions](https://github.com/foxfordkz-cyber/stupits-karaganda/actions/runs/41091830510): Node 22/24 на Windows/Linux и Flutter. Новая версия CI дополнительно проверяет полный синтетический пакет; её статус относится только к соответствующему новому commit SHA.

Локальная проблема системного SDK решена использованием отдельной рабочей копии соответствующей официальной версии; системный SDK не изменялся. Вызовы Flutter фиксируют --no-version-check, чтобы проверка не зависела от поиска обновлений SDK. Необязательный --offline ограничивает pub get локальным кешем и явно записывается в evidence.

Это проверка инженерной готовности интеграции. Реальные модули команды, проверка носителем, независимая разметка качества и итоговый исправленный файл остаются отдельными результатами. Число пройденных тестов не является precision/recall детектора.
