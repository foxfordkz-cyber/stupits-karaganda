# Скриншоты для README

Три необработанных снимка интерфейса Qazaq Loc QA сделаны 31.10.2026 в браузере
на локальной странице. Использован сохранённый синтетический результат
`npm run verify-team`: `team-pipeline/run/report.html`.

Входы — только `fixtures/synthetic/source.arb`, `target.arb` и `glossary.csv`.
Core и Language выполняли настоящий анализ, Тони формировал HTML. В этом прогоне
получены 6 находок. Общий формат поддерживает 11 категорий; покрытие шести категорий
в данном отчёте не является оценкой качества детектора.

| Снимок | Состояние интерфейса |
|---|---|
| `review-overview.jpg` | Начальная сводка, без рабочих или человеческих решений |
| `placeholder-detail.jpg` | Карточка `demoParcelNotice`: `{recipient}` / `{recipent}` |
| `expert-report.jpg` | Экспертный режим; подтверждения и проверенные исправления отсутствуют |

При съёмке менялись только выбранная карточка, режим отображения и положение
страницы. Реальные материалы, человеческие журналы и пользовательские данные
не загружались. UI-баннер «находки подготовлены заранее» обозначает сохранённый
синтетический HTML; эти находки получены детекторами, а не взяты из `report.sample.json`.
