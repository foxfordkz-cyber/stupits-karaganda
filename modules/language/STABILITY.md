# Проверка устойчивости перед интеграцией

31 октября 2026 года выполнена локальная проверка версии 1.1.0. Эта проверка относится к модулю Бекзата. Затем модуль подключён к `foxfordkz-cyber/stupits-karaganda` через `check.mjs` и `team_cli.py`; общий pipeline-контракт и точные хэши проверяются существующим валидатором команды. Состояние опубликованного сайта этим аудитом не подтверждено; GitHub CI нужно смотреть для конкретного опубликованного коммита.

Обнаруженные и исправленные случаи:

| Триггер | До исправления | Теперь |
|---|---|---|
| NaN, неподдерживаемый объект, циклические метаданные, одиночный Unicode surrogate | Хэширование/сериализация прерывала весь анализ | Запись изолируется, валидные записи дают результат |
| Повреждённая SQLite-база | Необработанная ошибка; открытый handle мешал Windows закрыть/переместить файл | База закрывается и сохраняется; локальный отчёт partial; новые вызовы модели запрещены |
| SQLite перешла в read-only во время работы | Ошибка записи прерывала анализ | Кэш становится недоступным, локальные проверки продолжаются |
| Адаптер пишет бесконечный/слишком большой stdout | Ограничение проверялось после накопления всего ответа | Ограничение проверяется во время чтения, процесс прерывается |
| Адаптер завис или не читает stdin | Общая зависимость от поведения communicate | Ограниченный ввод через временный файл, timeout и завершение прямого процесса |
| Адаптер пишет много stderr | Накопление stderr в памяти | stderr отбрасывается без сохранения закрытых сообщений |
| Ошибка сериализации отчёта | Мог оставаться частичный общий `.tmp` | Уникальный временный файл очищается, прежний отчёт сохраняется |
| Очень большой вход/запись/ответ | Не было согласованных пределов | Ограничения размеров и количества записей документированы в README |

Новые regression tests используют только синтетические данные. Они реально запускают тестовые подпроцессы с timeout, переполнением stdout и большим stderr. Пределы исходного subprocess API проверены по [официальной документации Python](https://docs.python.org/3/library/subprocess.html): буферизация `communicate` не подходит для неограниченного вывода.

Общий запуск тестов:

```text
python -m unittest discover -s tests -v
```

Интегратор должен запускать анализ как фоновое задание. Исключения конфигурации/файловой системы и код `1` превращаются в ошибку задания, а не остановку веб-процесса; код `2` сохраняет частичный отчёт. Одновременные платные задания с одним кэшем следует сериализовать. Отчёт для UI читается после итогового `metrics.json`; для публикации нескольких файлов нужна транзакция/переключение каталога на уровне сервера.

Этот модуль не может подтвердить доступность сайта, состояние базы сайта, секреты deployment, HTTPS, лимиты хостинга, health-check, rollback или нагрузочную устойчивость frontend/backend. Такие проверки выполняются в репозитории интегратора после получения доступа. Исходные выгрузки, частные отчёты и кэш остаются вне Git; схема находки и `reviewed_by_human=false` сохранены.
