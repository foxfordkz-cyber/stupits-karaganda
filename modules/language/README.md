# Языковая диагностика — Бекзат

Владелец этой области: Бекзат. Здесь подключается языковой модуль; модель и алгоритмы ещё требуется реализовать.

Вход: bundle по общей схеме и согласованный глоссарий. Выход: официальный report с `glossary_violation`, `inconsistent_term`, `machine_translation_suspect`, `orthography`, `wrong_language`, `suffix_harmony`.

Используйте source, target, имя ключа, раздел, доступное описание и дополнительные языки. Каждая находка должна объяснять конкретную проблему. Валидируйте формат и проверяйте, что цитируемый фрагмент существует. Не считайте отсутствие казахских букв достаточным доказательством другого языка. Учитывайте словоформы, сленг, бренды и сомнительные случаи.

Машинные находки получают `reviewed_by_human: false`. Исправления остаются предложениями до решения носителя. Настройки, версия модели, расходы, длительность и кэш записываются отдельно от официального report.

Начните с синтетических записей, затем проведите небольшой измеряемый пилот. Не выдавайте confidence модели за точность. Передайте запуск, тесты, ограничения и способ отключения внешнего API. Общие схемы и зависимости согласуйте с интегратором.
