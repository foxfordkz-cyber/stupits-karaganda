# Передача Core & CLI — Дамир

Техническая реализация модуля завершена в ветке `codex/core-cli` на базе
`62fa3a8` интегратора. Изменены только `modules/core/` и тесты внутри него.
Общие схемы, зависимости, исходные выгрузки и модули других участников не изменены.

## Запуск

На этом Windows-компьютере из любой папки:

```bat
C:\stupits-karaganda\modules\core\verify.cmd
```

На другом компьютере: Node.js 22+, `npm ci` из корня проекта, Flutter в PATH;
затем `node modules/core/scripts/verify.mjs` из корня. Проверка запускает
`npm test`, `npm run check` и настоящий Flutter на искусственном экспорте,
включая отказ выпуска при ошибке компилятора. Это не проверка реальных переводов человеком.

Проверка произвольной новой пары ARB из корня проекта:

```bat
modules\core\locqa.cmd check --source data/intl_ru.arb --target data/intl_kk.arb --glossary private/glossary.csv --out outputs/core-new-run
```

`--out` должен быть новым каталогом. Если `@@locale` отсутствует, добавьте
`--source-locale ru --target-locale kk`. Отчёт, все вхождения, метаданные,
структурная диагностика, хэши и план неоднозначностей сохраняются отдельно.
Коды завершения: 0 — нет находок, 1 — находки, 2 — структура/вход/отказ экспорта.

Экспорт после получения настоящих решений по точным версиям:

```bat
modules\core\locqa.cmd export --source data/intl_ru.arb --target data/intl_kk.arb --reviews private/reviews.json --out submission/core-approved-new --verify-flutter
```

Для конфликтующих target-дублей дополнительно передаётся
`--resolutions private/duplicate-resolutions.json`. Некорректный исходный baseline
сначала требует согласованного решения интегратора с сохранением оригиналов и аудита.
Пустой журнал не разрешает исправлять переводы. Команда не создаёт одобрений.

## Границы готовности

Технический кандидат на реальных данных прошёл `flutter gen-l10n`, но это
не утверждённый `intl_kk_fixed.arb`: у него есть отсутствующие переводы,
непроверенные человеком предложения и изменения имён, ещё не проверенные
по исходникам игрового клиента. Закрытый манифест хранит точные версии и причины.
Исходная пара не выдаётся за совместимую с Flutter.

Экспорт строго связывает решения с source/original/approved-хэшами, сбрасывает
неподтверждённые старые отметки и запускает независимый release gate интегратора.
Делегирование ИИ не подменяет чтение конкретного перевода человеком.

Оценка длины эвристическая; ширина виджета неизвестна. Технические символы
проверяются консервативно. Полнота и качество языка, личность проверяющего,
precision/recall скрытого набора этим модулем не устанавливаются. Глоссарий
используется только для исключений совпадающих терминов, не для морфологии.

Команды адаптеров и полный API описаны в [README.md](README.md).
