# Ядро — Дамир

Владелец этой области: Дамир. Это точка подключения модуля, его реализация ещё требуется.

Вход: исходный и целевой ARB, глоссарий. Выход: bundle по общей схеме и report с типами `untranslated`, `same_as_source`, `placeholder_mismatch`, `plural_mismatch`, `length_overflow`. Предусмотрите обязательную команду кейса `locqa check`; конкретный способ подключения согласуйте с интегратором.

Сохраняйте вхождения, позиции, разделы и метаданные при чтении. Дубли и ошибки структуры выводите отдельно. ICU проверяйте структурно; допустимые plural-категории зависят от языка. Для совпадений с оригиналом нужны исключения, длина без настоящего UI остаётся эвристикой.

Экспорт применяет только актуальные решения из reviews и сохраняет существующие метаданные. Отметки `@key.x-locqa` описаны в [контрактах](../../docs/CONTRACTS.md). Сохраняйте технические токены, теги и специальные символы. Не изменяйте исходники.

Начните с `fixtures/synthetic/`, включая edge-cases и flutter-valid. Передайте команду запуска, тесты, ограничения и результат настоящего Flutter-прогона. Общие схемы и зависимости меняет интегратор.
