# Разбор согласованных синтетических кандидатов

Основание: [report.sample.json](../../fixtures/synthetic/report.sample.json) и
[синтетические исходники](../../fixtures/synthetic/README.md). Это заметки ИИ,
не решения носителя. Исходные предложения не перезаписываются. Статус всех строк
ниже — `pending`; проверивший и одобренная версия отсутствуют.

| Ключ | Предварительное решение для обсуждения |
|---|---|
| `demoMissingExitLabel` | `Маяк терезесін жабу` сохраняет действие закрытия. Проверить: окно UI или физическое окно маяка; название объекта по игровому контексту. |
| `demoUntranslatedAction` | `Ай сандығын ашу` — кандидат для кнопки. Уточнить, является ли «лунный сундук» именем предмета, и сохранить это имя последовательно. |
| `demoParcelNotice` | Исправить `{recipent}` на `{recipient}` обязательно для техники. Вариант `Сәлемдеме: {recipient}` неявно передаёт получателя. Для поля получателя предложен `Сәлемдеме алушы: {recipient}`. Требуется чтение носителем в контексте UI. |
| `demoTokenBalance` | Вариант с `other` устраняет синтаксический дефект. Различие plural-категорий с RU допустимо. Проверить каждую ветвь и отображение чисел, не копировать русские категории автоматически. |
| `demoGuildHall` | `Бірлестік залы` соответствует условию данного теста. Не переносить запрет клан на реальные строки без различения механик клана и гильдии. |
| `demoShortTab` | `Карта` сохраняет смысл короткой вкладки и может совпадать с RU. Длина по символам не подтверждает переполнение экрана; нужен реальный UI. |
| `demoNaturalNotice` | `Сіз бағытты сәтті аяқтадыңыз` устраняет явно неестественный порядок слов. Для маршрута поездки обсудить `Сіз маршрутты сәтті аяқтадыңыз`; выбор зависит от уже принятого термина. |
| `demoTicketCounter` | `Қолжетімді купондар` — кандидат. Сначала проверить, что талон и купон обозначают один ресурс, и сравнить `demoTicketHelp`. Разные ресурсы не унифицировать. |
| `demoInviteName` | `Шақыру алушы: {player}` избегает фиксированного окончания у неизвестного имени. Подходит для подписи получателя; в полноценном уведомлении требуется сохранение синтаксиса и действия. |
| `demoQuestionLabel` | `Сұрақ` — предложенное исправление буквы ұ. Не расширять его в глобальную замену у → ұ. |
| `demoAirshipAudio` | `Дирижабль дыбысының баптаулары` — кандидат для звуков конкретного транспорта. Если это общие настройки звука внутри экрана транспорта, нужна другая привязка к контексту. |

Наличие правдоподобного варианта не требует принять исправление. После любой
доработки человек перечитывает финальную версию; проверка технических элементов
сама по себе не подтверждает смысл и естественность.

## Точные редакторские варианты, версия 2

Ниже закреплён конкретный вариант для чтения. У двух предложений модели
предлагается изменить формулировку: `demoParcelNotice` и `demoNaturalNotice`.
Остальные девять формулировок модели сохранены; это не новые исправления ради счёта.
Фразы сравнивались с доступными синтетическими RU/KK. Игровые экраны не предоставлены.

| Ключ | Текст для чтения носителем | Основание и оставшийся вопрос |
|---|---|---|
| `demoMissingExitLabel` | `Маяк терезесін жабу` | Сохраняется закрытие окна. Неизвестно, физическое ли это окно или окно интерфейса. |
| `demoUntranslatedAction` | `Ай сандығын ашу` | Сохраняется открытие сундука. Название «лунный сундук» может требовать продуктового термина. |
| `demoParcelNotice` | `Сәлемдеме алушы: {recipient}` | Явно назван получатель и восстановлено точное имя токена. Вариант предназначен для подписи поля получателя. |
| `demoTokenBalance` | `{count, plural, one{{count} жетон қалды} other{{count} жетон қалды}}` | Сохранён count, добавлен other. Ветки one/other намеренно не различаются по тексту. |
| `demoGuildHall` | `Бірлестік залы` | Только условная терминология синтетического набора. |
| `demoShortTab` | `Карта` | Подпись соответствует исходнику; совпадение с RU допустимо в этом значении. Размеры вкладки ещё неизвестны. |
| `demoNaturalNotice` | `Сіз маршрутты сәтті аяқтадыңыз` | Исправлен порядок слов, сохранены вежливое обращение и завершённое действие. Вместо более общего бағыт оставлено маршрут — то же понятие, что в RU и исходном KK. |
| `demoTicketCounter` | `Қолжетімді купондар` | Согласуется с `demoTicketHelp`: `Купонды пайдаланыңыз`. В реальной игре необходимо подтвердить, что это один ресурс. |
| `demoInviteName` | `Шақыру алушы: {player}` | Получатель приглашения назван без угадывания окончания неизвестного имени. Проверить, что это подпись, а не полная реплика. |
| `demoQuestionLabel` | `Сұрақ` | Исправлена конкретная буква в слове; глобальная замена у → ұ не предлагается. |
| `demoAirshipAudio` | `Дирижабль дыбысының баптаулары` | Предложение относится к звукам дирижабля. Если это общие настройки звука, потребуется уточнение. |

Технический статус каждого варианта сохраняется в JSON-пакете вместе с SHA-256
предложения и исходной пары. Никакая строка таблицы не является записью `reviews`.
Рабочие пакеты и история редакторских изменений находятся в игнорируемом
`private/linguistics/editorial-002/`; в Git передаются инструкция и этот разбор.
