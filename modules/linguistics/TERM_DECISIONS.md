# Спорные термины: предложения для решения носителем

Рабочая версия 1. Все решения ниже имеют статус `pending_human_review`.
Автор предложений — ИИ; проверивший, время проверки и одобренная версия отсутствуют.
Это уточнение комментариев [глоссария](glossary.csv), не список обязательных замен.

| Понятие | Предпочтение для указанного контекста | Варианты и исключения | Что решить человеку |
|---|---|---|---|
| Инвентарь | `Заттар` для вкладки с вещами | `Инвентарь` как знакомое игрокам название; `заттар тізімі` только если это действительно список | Понятно ли название без пояснения и охватывает ли экран экипировку? |
| Задание / квест | `Тапсырма` в нейтральном интерфейсе | `квест` возможен в речи игроков; миссия может обозначать другую механику | Являются ли задания, квесты и миссии одной сущностью? |
| Фракция | `Фракция` как название игровой системы | `ұйым` допустимо для организации, если не стирает различия механик | Как в игре различаются фракция, организация и клан? |
| Клан / гильдия | `Клан`; `бірлестік` для гильдии только в данном тесте | Слово `бірлестік` не должно автоматически заменять клан во всей игре | Нужен отдельный термин для каждой сущности реальной игры |
| Аренда | `Жалға алу` со стороны арендатора | `жалға беру` со стороны владельца; без стороны сделки одна универсальная кнопка опасна | Кто совершает действие на конкретном экране? |
| Скин | `Скин` для косметического предмета | `кейіпкер келбеті` поясняет облик персонажа, но не подходит всем скинам оружия и машин; `тері` не использовать в этом смысле | О каком объекте идёт речь и нужен ли краткий термин? |
| Донат | `Ойын ішіндегі сатып алу` для покупки за реальные деньги | Это не синоним `қайырымдылық`; покупка валюты может называться `ойын валютасын сатып алу` | Покупается товар/валюта или происходит безвозмездное пожертвование? |
| Появление / респавн | `Пайда болу` для появления | `қайта пайда болу` для повторного появления; `спавн` — разговорный вариант, не общий термин для возрождения | Различить первое появление, телепортацию и возвращение после смерти |
| Кулдаун | `Қайта қолдануға дейінгі уақыт` для таймера способности | В короткой подписи можно обсуждать `күту уақыты`; это не восстановление здоровья | Хватает ли места и ясно ли, какого действия ждут? |
| Лут | `Олжа` для полученных вещей | `лут` как разговорный вариант; добыча ресурсов — другой смысл | Предметы после победы, случайная награда или процесс сбора ресурсов? |
| RP / NPC / VIP | Сохранять точную метку в интерфейсе | Давать пояснение в подсказке; NPC — `ойыншы басқармайтын кейіпкер` | Это имя режима/статуса или обычное слово в предложении? |
| Grand Mobile | Сохранять написание названия | Для связи с предложением использовать подходящее родовое слово, например `Grand Mobile ойынында` | Проверить падеж и смысл всего предложения, не добавлять одно окончание ко всем именам |

`пожертвование → қайырымдылық` в стартовом глоссарии относится только к
безвозмездной помощи. Эта строка не разрешает переводить игровой донат как
благотворительность. Если в реальных исходниках есть покупки, добавить отдельную
строку для конкретного действия после определения механики.

При выборе варианта человек фиксирует точные RU/KK/EN/comment, контекст,
допустимые варианты и исключения в `term-decisions.jsonl`. Если перед одобрением
меняется формулировка, требуется прочитать новый текст. Различающиеся словоформы
внутри согласованного значения не требуют новых терминологических решений сами по себе.

Пакет для чтения всех 40 терминов автоматически создаётся командой `prepare`
как `term-review.md`. Пустые поля в нём намеренно не заполнены от имени Айданы.
