# Передача модуля лингвистики

Ветка: `aidana/linguistics-glossary-review`, база `62fa3a8` из
`codex/integration-kit`. Изменения ограничены `modules/linguistics/`.

Передано: 40 черновых терминов RU/KK/EN с пояснениями, правила работы со
словоформами, заимствованиями, сленгом и именами, разбор 11 синтетических
кандидатов, CLI очереди проверки и аудита точных версий. Подробности и
демонстрационные команды находятся в [README](README.md).

Команда запуска после `npm ci`, из корня репозитория:

```sh
node modules/linguistics/cli.mjs prepare --bundle outputs/bundle.json --report outputs/report.json --out private/linguistics/run-001 --batch-size 25
```

Входы: bundle/report по существующим схемам. Выходы: таблица и JSON-пакеты,
снимки входов, незавершённый журнал терминов, пустой reviews. При подключении
готовых модулей достаточно передать их реальные файлы этими параметрами.
Корневые скрипты и конфигурацию pipeline при необходимости подключает интегратор.

Проверено 30 октября 2026:

- `npm test`: 153 теста, 152 успешны, 0 ошибок, 1 пропущен. Общий тест симлинков
  пропущен из-за ограничений среды. Все 9 тестов этого модуля успешны.
- `npm run check`: общие схемы и синтетические примеры валидны.
- `git diff --check`: ошибок пробелов нет.
- Команды нормализации общего синтетического примера, `prepare` и `audit`
  выполнены: 11 строк, 1 пакет, 40 черновых терминов, 0 человеческих решений.
- Проверено, что результаты в `private/linguistics/demo-001/` игнорируются Git.

Ограничения: реальной раздатки нет; нет одобрений носителя и оценки качества
реальных переводов. Варианты спорных терминов ещё не согласованы. Модуль не
проводит морфологический анализ, не меняет ARB и не запускает Flutter. Технический
аудит не удостоверяет личность человека и не доказывает сохранение смысла.
CSV служит для просмотра и заметок; решения оформляются по общему JSON-контракту.
Общие схемы, зависимости, исходные данные и остальные модули не изменены.
