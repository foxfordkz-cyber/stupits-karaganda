# Отчёт и интерфейс — Тони

Владелец этой области: Тони. Реализация интерфейса и финального HTML-отчёта ещё требуется.

Вход: официальный report и bundle для контекста. Выход: локально открываемый HTML-отчёт и reviews с завершёнными решениями человека. Начните с `fixtures/synthetic/report.sample.json`, не ожидая остальных модулей.

Покажите оригинал, текущий перевод, тип/серьёзность, evidence и предложение. Нужны фильтры, принятие, ручное редактирование, отклонение, экспорт и повторный импорт решений. Проверяющий должен быть указан явно. Незавершённые черновики храните отдельно от завершённых reviews.

Храните хэши точных исходных и одобренных текстов; изменение любого текста делает прежнюю проверку неприменимой. Не выставляйте человеческое одобрение по факту отображения карточки или массовой загрузки.

Если показываете макеты кнопок, обозначайте их как иллюстрацию риска длины без реальных размеров и шрифта игры. Сводка должна отличать кандидатов, подтверждённые находки и принятые исправления.

Передайте способ запуска, пример импорта/экспорта и тест восстановления решений. Общие схемы меняет интегратор.
